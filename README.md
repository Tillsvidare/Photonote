# Photonote

En mobilanpassad PWA för att fotografera visitkort och liknande och koppla anteckningar till varje bild.

## Funktioner

- Ta foto med kameran eller välj från galleri
- Skriv en kort anteckning till varje bild
- Redigera och radera poster
- Allt sparas lokalt på enheten (IndexedDB)
- Fungerar offline (service worker)
- Installerbar som app på telefonen

## Användning

Öppna appen i Safari (iOS) eller Chrome (Android) och tryck på **”Lägg till på hemskärmen”** för att installera den som en vanlig app.
